# Incubus — Quad Cortex + TONEX Tone Guides

Mike Einziger tones for **Morning View** (2001), built as a hybrid rig:

- **TONEX Pedal** supplies **Mesa Boogie** amp + cab captures (Trem-o-Verb / Dual Rectifier family — load your own IK or community captures).
- **Neural DSP Quad Cortex** supplies effects, scenes, mix EQ, and **MIDI Program Change** that recalls those TONEX presets.
- Pre-amp pedals (CS-3, PH-2, OC-2) sit **before** the FX Loop; delay and reverb **after**.
