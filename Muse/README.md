# Muse — Essentials Song Set · Quad Cortex + TONEX

Matt Bellamy tones for a **set of eight live/studio staples** (not one album), built as a hybrid rig:

- **TONEX Pedal** supplies **Diezel VH4** high-gain + **Vox AC30** clean captures (load IK / community Mesa-Diezel / AC30 models into banks 01–02).
- **Neural DSP Quad Cortex** supplies Pitch Shifter, Fuzz Factory stand-in, phaser, synth filter, delays, scenes, and **MIDI Program Change**.
- Pre-amp pedals (Pitch Shifter, fuzz, phase, synth) sit **before** the FX Loop; delay / dimension / reverb **after**.
